# موقع جمعية نفع القانونية

موقع ثابت (HTML/CSS/JS) باللغة العربية، منشور عبر GitHub Pages:
https://abosallh1421-sys.github.io/abosallh/

## الصفحات
| الصفحة | الملف |
|---|---|
| الرئيسية (الفكرة، الرؤية، الأهداف، الفئات المستهدفة، عبارات قانونية، آخر الأخبار) | `index.html` |
| اللوائح والسياسات | `regulations.html` |
| مجلس الإدارة والجمعية العمومية | `board.html` |
| أخبار الجمعية | `news.html` |
| انضم إلى الجمعية العمومية | `join.html` |

## الملفات المساعدة
- `assets/css/styles.css` — التنسيق وألوان الهوية (المتغيرات في أعلى الملف).
- `assets/js/script.js` — القائمة في الجوال، حركة الظهور، نموذج طلب العضوية.
- `assets/img/` — الشعار ورموز الهوية والرسومات.
- `assets/docs/bylaws-nafa.pdf` — اللائحة الأساسية.

## ملاحظات
- الأهداف وأسماء الأعضاء المؤسسين وشروط العضوية مأخوذة من اللائحة الأساسية.
- أسماء مجلس الإدارة لم ترد في اللائحة؛ تُضاف في قسم `#board` داخل `board.html`.
- نموذج طلب العضوية للعرض فقط ويحتاج ربطًا بخدمة إرسال (مثل Formspree) ليصل الطلب فعليًا.
