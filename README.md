# موقع جمعية الخير الخيرية

موقع تعريفي ثابت (HTML/CSS/JS) باللغة العربية يعرض:

- فكرة الجمعية
- الرؤية والرسالة والقيم
- أهداف الجمعية
- الفئات المستفيدة
- نموذج تواصل (تبرع / تطوع / طلب مساعدة)

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو انشره عبر GitHub Pages.

## التخصيص
- اسم الجمعية والنصوص: داخل `index.html`.
- الأرقام والإحصائيات: خاصية `data-count` في قسم الأرقام.
- الألوان: المتغيرات في أعلى `styles.css`.
- بيانات التواصل: قسم `#contact` في `index.html`.
- نموذج التواصل حاليًا للعرض فقط، ويحتاج ربطًا بخدمة إرسال (مثل Formspree) ليصل البريد فعليًا.
